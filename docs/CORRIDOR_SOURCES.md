# Corridor: Chattanooga ↔ Atlanta — data sources

Research for the `corridor` layer group (I-75, KCHA 35.04N −85.31W → KATL
33.64N −84.43W, via Dalton, Calhoun, Cartersville and Marietta). Every no-key
endpoint below was fetched once on 2026-09-15 and its shape captured under
`scripts/fixtures/corridor/` (trimmed). Corridor bbox used for upstream
queries: `-85.6,33.4,-84.1,35.3` (W,S,E,N); the polygon that actually clips
features lives in `src/layers/corridor/constants.js`.

## What is live without any key

`alerts`, `gauges` (+ series), `air`, `incidents` (TDOT + HC911) and `transit`
(MARTA through the transit proxy). `cams` needs `GA511_API_KEY` (GDOT) and/or
`TDOT_API_KEY`; `incidents` gains Georgia events with `GA511_API_KEY`; `transit`
gains CARTA with `CARTA_BUSTIME_KEY`. Keys are pasted in the POWER UP panel
(`GEORGIA 511`, `TDOT SMARTWAY`, `CARTA BUSTIME`) or `.env`. A missing key
answers `402 {error:'key_required', keyId}` and the sub-layer chip reads
`· KEY` with the variable name in its tooltip.

## Proxy contract (`/api/corridor`)

| Route                      | Cache              | Notes                                                                   |
| -------------------------- | ------------------ | ----------------------------------------------------------------------- |
| `GET /status`              | —                  | key presence (never values) + per-provider TTLs                         |
| `GET /alerts`              | 90 s               | corridor alerts with polygon/zone geometry (decimated rings)            |
| `GET /gauges`              | 10 min             | NWPS gauges inside the polygon                                          |
| `GET /gauges/<LID>/series` | 15 min             | last 24 h of observed stage for a listed gauge only                     |
| `GET /air`                 | 60 min (6 h stale) | AirNow reporting areas                                                  |
| `GET /incidents`           | 60 s (GA 2 min)    | merged TDOT + HC911 + GA511 with per-source status                      |
| `GET /transit`             | 20 s               | GTFS feed ids to poll + CARTA vehicles                                  |
| `GET /cameras`             | 60 min             | inventory (402 without a key)                                           |
| `GET /cameras/<id>/frame`  | none               | still image for a listed camera; `id` must be `ga511:<n>` or `tdot:<n>` |

Every reply carries `X-Corridor-Cache` (HIT/MISS/STALE/MERGED) and
`X-Corridor-Delayed: 1` when a refresh failed and the previous body is being
served (up to 15 min; the browser chip reads `· DELAYED`). Upstream fetches
never follow redirects, cap bodies at 8 MB and time out at 15 s (40 s for the
TDOT ArcGIS server, which is slow).

## I-75 centerline (bundled, not fetched at runtime)

`src/data/local_data/corridor/i75-centerline.geojson` was produced once with
the committed Overpass query `src/data/local_data/corridor/i75.overpassql`:

```
[out:json][timeout:120];
way["highway"="motorway"]["ref"~"^I 75(;|$)"](33.55,-85.55,35.20,-84.10);
out geom;
```

774 ways came back; the northbound carriageway was stitched by shared node
ids into one line (Atlanta 33.549N → Chattanooga 35.212N), then simplified
with Douglas–Peucker at 0.0003° (~30 m) to 230 vertices (5 KB). Re-running
needs a `User-Agent` header (Overpass answers 406 to a bare curl) and should
stay a one-off — Overpass has usage limits.

## Etiquette recap

- NWS: identifying `User-Agent` on every request; zone geometry cached forever.
- NWPS: hourly observations; list every 10 min, series on click only.
- AirNow backend: hourly; documented keyed API is the fallback.
- TDOT ArcGIS: 60 s, one envelope query; the server is slow — 40 s timeout.
- HC911: 60 s, 200 newest rows, dedup per incident, 6 h age cut-off.
- 511GA: quota is 10 calls/min — cameras hourly, events every 2 min.
- MARTA: 15 s proxy TTL (transit proxy), single-flight, text credit only.
- LiveATC: directory built offline by `scripts/liveatc-feeds-build.mjs`
  (`LIVEATC_MERGE=1 LIVEATC_PAGE_CACHE=.gev-cache/liveatc node scripts/liveatc-feeds-build.mjs KCHA`).
